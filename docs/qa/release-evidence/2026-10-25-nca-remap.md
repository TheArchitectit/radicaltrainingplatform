## 4. A gate that could not fail — found and fixed

**This is the finding of the row.** Before this work, the ship gate reported:

```
$ python3 scripts/redeye-gate.py NCA-75
== NCA-75 ==

✅ GATE PASS: every scored item carries a current passing verified log.
$ echo $?
0
```

It gated **nothing**. `gate_exam` looked only in
`content/exams/NCA-75/questions/`, which is an empty directory, so the item loop
ran zero times and `excluded == 0` printed the same success line as a fully
verified pack. The 140 real items are `NCA-75-Part{1,2,3-GapFill}.md` at the
repository root — where SPEC-06 requires them to stay (*"remapped bank items stay
in their original files"*) — and the gate could not see them.

If NCA content had ever been released, this gate would have certified it.

**Fixed in three parts:**

1. `collect_banks(exam_id)` finds pack banks **and** legacy root banks, matching
   them with the same `derive_exam_code` port `check-item-identity.py` uses, so
   the two gates cannot disagree about which items belong to an exam.
2. `parse_items(bank, exam_id)` takes the exam id rather than deriving it from
   `bank.parent.parent.name` — which for a root bank is the repository's own
   directory name.
3. `gate_exam` returns a `gated` count, and **`gated == 0` is a failure**:
   `NO BANKS: <exam> has no question banks — the gate has nothing to verify
   (this is a failure, not a pass)`. "Nothing gated" and "everything verified"
   can no longer print the same line.

After the fix:

```
$ python3 scripts/redeye-gate.py NCA-75
== NCA-75 ==
  EXCLUDED NCA-75/NCA-75-Part1.md/Q1: verdict is 'return'
  … 140 lines …
  EXCLUDED NCA-75/NCA-75-Part3-GapFill.md/Q60: verdict is 'return'

❌ GATE FAILURE: 140 item(s) excluded — nothing releases without a current
   passing verified log (REQ-REV-02/05)
$ echo $?
1
```

Two self-test cases pin it: a bank-less exam must fail rather than pass
vacuously, and the three legacy root banks must be discovered for `NCA-75`.

**This is the third gate in this package found green while enforcing nothing** —
after `brand-disclaimer-snapshot.mjs` (S47-14, a hardcoded filename nothing
matched) and the `generate-bundle-manifest.py` invocation (S47-13, wrong argument
shape). All three were green for several sprints. The pattern is worth naming:
*a gate is only as good as its most recent failure.*
