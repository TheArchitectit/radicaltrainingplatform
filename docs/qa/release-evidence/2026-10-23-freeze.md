```
python3 scripts/redeye-gate.py --all   →  exit 1
❌ GATE FAILURE: 49 item(s) excluded — nothing releases without a current
   passing verified log (REQ-REV-02/05)
```

All **49 scored items** (16 A+ Core 1, 8 A+ Core 2, 25 Network+) are excluded,
each named, every one for `verdict is 'return'`. Lane logs exist for all 49

**The freeze record states it plainly because the sprint's own acceptance

the RedEye gate's definition none of those items is releasable.** The demo can
run the set; the gate will not call it released. That gap is not closed here and
is not closable without the radredeye model-stage integration.
