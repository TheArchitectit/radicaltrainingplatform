## 1. What the project actually is

A local study app for Nutanix/CompTIA exams: a .NET 10 Core library that discovers Markdown
question banks, parses them, applies an errata overlay, scores sessions, and renders PDFs;
an Avalonia 12 desktop shell (study/test/review/stats/blueprint/export); a preserved WinForms
shell; and a 16 k-line static PWA that simulates Prism Element/Central for lab practice. The
PWA is linked into both desktop hosts as the "Lab Simulator".

Type signals matched: desktop app + static web app + content pipeline. Adapted axes: session
path (discovery → parse → score → export), state machine, persistence boundary, config surface,
plus a web asset/bridge contract axis.

Top three paths: (a) launch → catalog → start session → answer → score/export; (b) wrong-answer
review round-trip; (c) lab-simulator hosting in Desktop and on GitHub Pages.

## 2. What it does exceptionally well (do not change)

- Parser robustness: CRLF normalisation, BOM stripping, all answer-key grammar variants,
  provenance-comment filtering. Probe: every file parses; catalog counts equal parse counts.
- Errata overlay keyed `(file, id)` with per-entry guards, first-wins on duplicates,
  non-fatal on malformed files. Probe: both live corrections apply.
- Session scoring: `Exam:SourceFile:Id` keys, latest-attempt-wins, skip-as-miss that does not
  clobber an answered result, accuracy-over-answered vs score-over-total. 99.3 % covered.
- Option shuffle with a letter-reference escape hatch (35/2,378 stay unshuffled).
- Exam-code derivation from both folder layout and filename suffixes.
- Persistence primitives: atomic write-then-rename; session-id whitelist incl. reserved names.
- Shared DI composition root, covered by a test so a missing registration fails CI.
- CI hygiene that bites: content lint, import-resolution lint, blocking vuln gate with
  expiry-dated allowlist, compiled-DLL Windows.Forms scan, headless Avalonia smoke suite.

## 4. Genuinely missing (capability level)

- **Explain/KB panel in the Avalonia app**: `IReferenceService` is resolved in
  `MainWindow.axaml.cs:32,73` and never called. Only WinForms calls it.
- **Exam clock and passing score**: `ExamBlueprint.TimeLimitMinutes`/`PassingScore` are
  populated in `HardcodedBlueprintService` and read by nothing; Test mode only samples 75.
- **Domain metadata for most Nutanix questions**: probe shows 280/360 NCM-MCI, 240/400
  NCP-US, 175/335 NCP-AI, 123/363 NCP-CI, 60/260 NCA-75 questions carry `Domain == ExamCode`
  or a bare `Domain 3`, so StatsView's domain breakdown collapses to one bucket.
- **Any gate for the two surfaces that failed**: no test exercises the CEF/bridge end to end;
  no test clicks an option card; no test boots the PWA. `pwa-deploy.yml` publishes without
  the checks `build.yml` runs.
- **Coverage gate**: `HardcodedReferenceService` and `ExamPdfExporter` sit at 0 %.
- **Release integrity**: README references a tracked release zip, a BSD-3 `LICENSE`, and a
  `designguides/`/`validation/` layout; none exist. `packaging/*.metainfo.xml` declares MIT.
- **Desktop study-session persistence**: `ISessionStore` is only reachable through the lab
  bridge; closing the app loses a 400-question session.
