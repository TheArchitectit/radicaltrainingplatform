# CompTIA A+ Core 1 — Domain 1 beginner bank (mobile devices)

## Domain 1: Mobile Devices (220-1201)

### Q17
A user's phone has a battery that no longer holds a charge, and the back cover is visibly lifting. What should the technician do?
- A) Charge the phone fully and monitor it for a day
- B) Press the cover back into place and continue use
- C) Take the device out of service and replace the battery
- D) Place the phone in a cool room until the cover settles

**Answer: C**
A lifting cover together with lost capacity is the signature of a swollen cell, which is a safety hazard that calls for replacement rather than continued use. Fully charging it (A) adds energy to a failing cell. Pressing the cover down (B) conceals the condition. Cooling it (D) does not reverse the swelling.

### Q18
A phone's glass is cracked but every part of the screen still responds to touch. Which component is still working?
- A) The digitizer
- B) The battery
- C) The charging port
- D) The antenna

**Answer: A**
The digitizer is the touch layer that converts contact into input, and it is working if every area responds. The battery (B), charging port (C) and antenna (D) are unrelated to touch response, so none of them explains the observation.

### Q19
A phone will not charge with any cable, but the battery and the charger both work in another device. What should the technician check first?
- A) Replace the main board
- B) Reinstall the operating system
- C) Replace the battery
- D) Inspect and clean the charging port

**Answer: D**
A port packed with pocket lint prevents the cable from seating, which produces exactly this symptom and is fixed without parts. Replacing the main board (A) is far beyond the first check. Reinstalling the OS (B) does not address a physical connection. The battery (C) has already been tested in another device.

### Q20
A user wants one connector that can carry power, data and video and plugs in either way. Which connector should the technician recommend?
- A) Micro-USB
- B) USB-C
- C) Lightning
- D) USB Type-B

**Answer: B**
USB-C is reversible and can carry power, data and video when the port and cable support those features. Micro-USB (A) is not reversible and carries no video. Lightning (C) is Apple's older proprietary connector. Type-B (D) is the squarer connector used on printers and hubs.

### Q21
A user taps a phone against a payment terminal to complete a purchase. Which wireless technology is being used?
- A) Bluetooth
- B) Cellular
- C) NFC
- D) Wi-Fi

**Answer: C**
Near-field communication works at a few centimeters, which is what makes tap-to-pay both possible and hard to intercept at a distance. Bluetooth (A) has a much longer range. Cellular (B) connects to the carrier network. Wi-Fi (D) is a building-scale data link.

### Q22
A user turns on the phone's personal hotspot so a laptop can use the phone's cellular data, then connects the laptop with a USB cable instead of Wi-Fi. What is this arrangement called?
- A) USB tethering
- B) Bluetooth pairing
- C) Wireless charging
- D) Synchronization

**Answer: A**
Tethering shares the phone's data connection with another device over a cable, Bluetooth or Wi-Fi, and the cabled form is USB tethering. Bluetooth pairing (B) is the setup step for a Bluetooth link, not a cabled one. Wireless charging (C) transfers power inductively. Synchronization (D) copies contacts and files.

### Q23
A company must enroll 40 phones so that each receives the same Wi-Fi, mail and policy configuration and can be wiped if lost. Which system provides this?
- A) A local administrator account on each phone
- B) A printed setup guide for each user
- C) A shared cloud drive with the settings listed
- D) A mobile device management service

**Answer: D**
Mobile device management enrolls a device, pushes configuration profiles and enforces policy including remote wipe, which is exactly the requirement at this scale. Local administrator accounts (A) do not exist on managed mobile platforms in that form. A printed guide (B) leaves 40 devices configured differently. A cloud drive of settings (C) still requires manual configuration on each phone.

### Q24
A user's mail application on a phone fails to connect, and the account was set up manually. Which settings should the technician verify first?
- A) The phone's wallpaper and font size
- B) The server name, port and encryption setting
- C) The number of photos stored on the device
- D) The screen brightness setting

**Answer: B**
A manual mail configuration depends on the server address, port and TLS setting matching what the mail service requires, and any one of them being wrong produces exactly this failure. Appearance settings (A) and brightness (D) have no bearing on mail. Photo storage (C) is a capacity issue, not a connection issue.

### Q25
A company policy requires that a phone's camera be disabled on site and that the device report when it leaves a defined area. Which pair of capabilities delivers this?
- A) Anti-virus scanning and a firewall
- B) Encryption and a passcode
- C) A configuration profile and geofencing
- D) A VPN client and a proxy server

**Answer: C**
Configuration profiles enforce device restrictions such as disabling the camera, and geofencing triggers an action when the device crosses a defined boundary. Antivirus and a firewall (A) address malware and traffic. Encryption and a passcode (B) protect stored data and access. A VPN and proxy (D) protect and route network traffic.
